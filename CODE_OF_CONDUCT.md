# Code of Conduct

## Our Pledge

We pledge to make participation in the PI Platform project a harassment-free experience for everyone, regardless of background, identity, or beliefs.

## Our Standards

- Be respectful, constructive, and professional
- Focus on deterministic, governance-first technical merit
- Welcome newcomers and help them understand the architecture
- Respect the hard boundaries: no LLM in core, no probabilistic decision-making in execution paths

## Unacceptable Behavior

- Introducing non-deterministic or probabilistic components into Layers 1–3
- Attempting to bypass the `ExplicitCompositionRequest` boundary
- Disrespectful or exclusionary language or behavior

## Enforcement

Report concerns to the maintainers. All reports are handled confidentially.

## Scope

This Code of Conduct applies within all project spaces and public representation.
