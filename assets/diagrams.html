PI Runtime Specification v1.0 — Visual Diagrams

Diagram 1: Artifact Lifecycle State Machine

Immutable progression: once FROZEN, an artifact never returns to CREATED.

Diagram 2: End-to-End Execution Flow

Layer 4 is the only boundary where natural language is permitted. All core communication is strict JSON via ExplicitCompositionRequest.

Diagram 3: Receipt Chain & Boundary Chaining

Receipts and boundaries each form independent hash chains within the OrchestrationLedger. Events form a separate chain in the ReplayLedger.

Diagram 4: Deterministic Shard Assignment

Workers are deterministically partitioned by SHA-256 hash. Phase barriers synchronize across all shards before pipeline advancement.

Diagram 5: Phase State Machine

The 7-phase pipeline order is a compile-time constant. Every pipeline, regardless of configuration, traverses all phases sequentially.

Diagram 6: Trust Zone & Extension Lifecycle

Extensions progress through mandatory inspection stages. Sandbox experimental extensions can never gain governance authority.
