Phase 4–6: Structure & Stability

  • • Quorum: Intersection-based consensus, never majority voting
  • • Entropy: 5-dim stability monitoring, HALT on regression
  • • All phases observational-only — never mutate runtime state

Governance Supremacy

  • • CRITICAL violations: Provenance broken, Auth mutation, FSM overflow, Entropy regression
  • • Non-critical: Orphaned artifacts, unverified transitions → WARNING, continue
  • • Monotonic promotion: INIT → ... → VERIFIED only
  • • CONTESTED claims may promote with new evidence; REJECTED never promotes
