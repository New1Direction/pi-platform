pi-semantic-recon Pipeline

Deterministic extraction nodes + governance-bound verification plane

Extraction Pipeline

  • • Node 0: Acquisition Gateway — canonicalizes raw HTTP into packets
  • • Node 1: Ingress Parser — parses bytes, parameterizes paths
  • • Node 2: Structural Extractor — flattens JSON into field paths
  • • Node 3: Semantic Typer — UUID, JWT, EMAIL pattern detection
  • • Node 4: Flow Mapper — dependency graph + replay equivalence
  • • Node 5: Spec Synthesizer — OpenAPI from verified IR

Verification Plane

  • • Phase 1: Provenance — every claim traced to raw traffic
  • • Phase 2: Replay — 4-class equivalence taxonomy
  • • Phase 3: Auth — 5-class session rotation taxonomy
  • • Phase 4: FSM — bounded protocol state machine
  • • Phase 5: Quorum — intersection (not voting!)
  • • Phase 6: Entropy — stability instrumentation layer

Governance Kernel

  • • Monotonic state machine: INIT → ... → VERIFIED
  • • HALT on CRITICAL violations (provenance broken, auth mutation)
  • • WARNING on non-critical (orphaned artifacts, unverified transitions)
  • • Schema gate validates before synthesis
  • • Entropy monitor detects divergence in real-time
  • • Objective tracker prevents goal drift
