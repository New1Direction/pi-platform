# PI Platform

PI Platform is a **governed, deterministic** AI agent infrastructure. Code and data pass through a chain of 248 specialised micro-agents. Every execution is cryptographically recorded in an append-only ledger and can be replayed byte-for-byte.

<Callout type="info">
**Production status:** 248 agents registered · All CI checks green · Tenant-scoped audit trail live
</Callout>

## What it does

```
Your code or data
      │
      ▼
AgentRouter (keyword dispatch, 248 routes)
      │
      ▼
Micro-Agent (Pydantic I/O, WASM sandbox)
      │
      ▼
StateLedger (content-addressed, tamper-evident)
      │
      ▼
Replay API  ──►  PASSED / WARN / REJECTED
```

Agents span every major security domain:

| Domain | Example agents |
|--------|----------------|
| Regulatory | HIPAA PHI scanner, PCI DSS v4.0 auditor |
| Mobile | OWASP MASVS/MASTG static analyser |
| Infrastructure | IAM policy, Kubernetes RBAC, Terraform drift |
| Crypto | Key-strength, certificate expiry, SSH cert gaps |
| Supply chain | SCA, SBOM, typo-squatting, dependency confusion |
| Bot & WAF | Evasion-pattern sentry (AWS WAF, DataDome, Cloudflare) |
| Blockchain | Smart-contract reentrancy, integer overflow |
